# LibreCourseUY Brand

Official brand assets and visual identity resources for [LibreCourseUY](https://librecourse.uy/).

This repository contains the canonical versions of the LibreCourseUY logo and related visual assets used across our projects, community spaces, documentation, and events.

## Assets

```text
logo/
├── librecourseuy.svg
├── librecourseuy-light.svg
├── librecourseuy-dark.svg
└── librecourseuy.png
```

SVG files should be preferred whenever possible.

## Usage

You are welcome to use these assets when referring to LibreCourseUY, its community, or its projects.

Please:

* Keep the logo proportions intact.
* Avoid modifying the core logo in ways that could cause confusion about the LibreCourseUY identity.
* Do not use the LibreCourseUY name or visual identity to imply endorsement, affiliation, or official status where none exists.

If you need a new format or variation, consider opening an issue or pull request instead of maintaining a separate version.
